# Hi, I'm Nishat Tasnim Mahi

AI/ML Researcher and Full-Stack Developer based in Bangladesh. I work at the intersection of Natural Language Processing, Deep Learning, and production software engineering. My research focuses on neural text style transfer, low-resource NLP for Bengali, and AI-assisted reasoning systems.

## What I Work On

**AI & Machine Learning**
- Neural text style transfer using GRU-based sequence models (StyleNet)
- Low-resource NLP for Bengali language
- LLM integration for medical reasoning and knowledge retrieval
- Document processing pipelines with OCR for RAG systems

**Full-Stack Engineering**
- REST APIs with Django and Django REST Framework
- Modern frontends with Next.js and TypeScript
- JWT authentication, CORS, and production deployment
